# カラオケどこ得？

GitHub Pages用の、外部API・ビルド工程なしで動く静的サイトです。

## 配置手順（重要）
1. ZIPを展開します。
2. 展開したフォルダ**そのものではなく中身**（`.github`、`site`、`README.md`）を、GitHubリポジトリの最上位（ルート）に配置します。
3. GitHubの `Settings → Pages → Build and deployment → Source` を `GitHub Actions` にします。
4. `Actions` タブで `Deploy karaoke-dokotoku to GitHub Pages` が成功すれば公開完了です。

## 機能・制限
- 7チェーンの料金目安を比較し、合計/1人あたり/1人1時間あたりで表示・並び替え
- 人数、利用時間、平日/週末、会員/学生条件、ドリンク、ポテト、アルコール条件に対応
- スマホ画面対応。外部APIやビルド工程は不要
- 料金は動作確認用の仮データで、全国の実店舗料金を調査したものではありません
- 出発地・移動方法の入力欄はありますが、経路検索や交通費計算はまだ未実装です

料金データを変更する場合は `site/app.js` の `chains` 配列を編集してください。
