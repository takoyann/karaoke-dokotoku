# カラオケどこ得？

人数・利用時間・追加注文・移動手段を考慮して、カラオケ店を「実質円/h」で比較するWebアプリ。

## 現在の状態

- 条件入力UI
- 店舗JSON読み込み
- 人数を考慮した料金計算
- ポテト食べ放題 / 通常ポテト
- アルコール飲み放題
- 移動時間を含めた円/h計算
- 比較結果のランキング表示
- 料金差・移動時間・ポテト等の簡易コメント

現在の `data/stores.json` は**動作確認用のサンプルデータ**。

4. 地図表示

7. 駐車料金・高速料金
